🧪 How the Fix Works

  1. Original Problem: /en/devices/favicon/favicon-16x16.png was incorrectly mapped to /assets/images/devices/favicon/favicon-16x16.png
  2. New Logic: Uses the Referer header to extract the correct context
  3. Referer Processing: Removes everything after the last '/' from referer URL
  4. Path Calculation: Subtracts referer base from full request URL to get relative path
  5. Final Mapping: /assets/images/ + relative path
